# Où trouver les résultats

Page d'aiguillage : elle ne fait que pointer vers la source qui fait foi.

| Question | Source qui fait foi |
|---|---|
| Synthèse des pré-enregistrements 1 à 9 | [[RESULTS]] |
| Protocole d'un test | `PREREGISTRATION_<n>.md` (ex. [[PREREGISTRATION_12]]) |
| Rapport détaillé d'un test | `reports/` (ex. [[reports/prereg12_report]]) |
| Rapports n° 10 et suivants | `reports/prereg1*_report.md`, [[reports/robust13_report]] (pas encore repris dans RESULTS.md) |
| Chiffres bruts, trades, courbes | `results/<expérience>/` (csv, parquet, png, run.log) |
| Rendements par session | [results/sessions/RAPPORT.md](../../results/sessions/RAPPORT.md) |
| Rendements par session de l'or (GC) | [[reports/gc_sessions_report]], `results/gc_sessions/` |
| Compteur d'essais courant | [[wiki/hot]] (relu dans le dernier rapport) |
